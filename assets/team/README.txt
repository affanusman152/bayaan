What makes a good file here
---------------------------
* PORTRAIT crop, not landscape. The cards are 3:4 (taller than wide).
* Frame the face in the UPPER half — the bottom of every card is covered by a
  dark gradient so the name and role stay readable, and the crop is anchored
  near the top (`object-position: center 18%`).
* Roughly 800x1067px is plenty. Bigger just costs load time.
* .jpg only, unless you also change the path in js/data.js.

Missing files are fine
----------------------
Any member without a photo falls back to the بیان placeholder card, and a file
that fails to load removes itself and falls back the same way. So you can add
these one at a time — a half-finished set will not leave holes on the page.

Changing a name or adding a member
----------------------------------
The filename comes from the `photo:` field in js/data.js, not from the person's
name. Add or edit that field and use whatever filename you put here.
